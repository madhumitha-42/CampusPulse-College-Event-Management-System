# CampusPulse Demo Guide

1. Start the API and frontend workflows.
2. Open the frontend preview.
3. Sign in as `admin@campuspulse.demo` / `CampusDemo!2026`.
4. Show the coordinator dashboard totals and recent events.
5. Open Categories, create a category, edit it, and remove it if unused.
6. Create an event with a future date, valid times, capacity, and deadline.
7. Open the event detail and edit the event from the management list.
8. Sign out and sign in as `mira@campuspulse.demo` / `StudentDemo!2026`.
9. Search and filter the event directory.
10. Open an event and register.
11. Open My registrations and show the persisted registration.
12. Try registering for the same event again to show the conflict message.
13. Cancel the registration.
14. Return to the coordinator account and open Participant management.
15. Explain the database-backed participant count and status update.
16. Use the Postman collection to show the same REST endpoints.
17. Explain the React → JWT API → Django ORM → SQLite architecture.
